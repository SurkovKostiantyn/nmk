# Заготовка для лабораторної роботи №10

Каталог містить заготовку (еталонний варіант) коду для лабораторної роботи №10 «Вступ до ООП у PHP. Рефакторинг проєкту "Менеджер завдань"».

Файли слугують стартовою точкою для виконання практичних завдань лабораторної роботи (зокрема, якщо попередні роботи не були завершені вчасно), а також зразком для перевірки коректності переведення процедурного коду на класи та методи.

## Структура та опис файлів у папці

Опис файлів проєкту:
- `Task.php` - клас моделі завдання `Task`, що містить типізовані властивості, валідацію в конструкторі, бізнес-методи перевірки дедлайну й статусу (`isOverdue`, `complete`, `getStatusLabel`), а також методи серіалізації (`toArray`, `fromArray`);
- `TaskRepository.php` - клас-репозиторій для роботи зі сховищем завдань, що інкапсулює операції читання, додавання, видалення, оновлення статусу та збереження колекції об'єктів у JSON;
- `index.php` - головна сторінка вебзастосунку з перевіркою авторизації через сесію, обробкою POST-запитів (`add`, `complete`, `delete`), відображенням списку завдань та форми створення нового завдання;
- `login.php` - сторінка аутентифікації користувача з формою входу, валідацією облікових даних та ініціалізацією сесії `$_SESSION`;
- `tasks.json` - локальний файл збереження даних у форматі JSON із початковими тестовими записами завдань;
- `readme.md` - документація з описом призначення файлів поточної папки та інструкцією до запуску.

## Як запустити заготовку

Порядок дій для запуску:
- відкрити термінал у каталозі `lab_10`;
- виконати команду запуску вбудованого вебсервера `php -S localhost:8000`;
- перейти в браузері за посиланням `http://localhost:8000/`;
- у формі авторизації ввести тестовий логін `admin` і пароль `12345`.
