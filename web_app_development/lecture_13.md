# Лекція 13 (2 години). Управління серверним станом та кешування даних: TanStack Query (React Query)

## Тема лекції

Чому Server State кардинально відрізняється від Client State (асинхронність, необхідність кешування, застарівання даних). Робота з TanStack Query: автоматичний фетчинг, кешування (Stale-While-Revalidate), обробка станів завантаження та помилок. Мутації даних (useMutation), інвалідація кешу та оптимістичні оновлення (Optimistic UI) без очікування відповіді сервера.
