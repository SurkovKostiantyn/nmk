# Практичне заняття №9 (2 години). Комплексний аудит безпеки, Core Web Vitals у Lighthouse та Docker-контейнеризація

## Методичні відомості

- відповідність лекціям - поглиблює та закріплює практичні навички Лекція 17 та Лекція 18;
- мета заняття - Освоїти методики аудиту безпеки, оптимізації веб-показників та підготовки фронтенд-додатку до промислової експлуатації.;
- практичні завдання - Аудит безпеки коду: запобігання XSS-атакам, налаштування CSP-заголовків, безпечне збереження авторизаційних даних; аудит метрик LCP, INP, CLS у Google Lighthouse; написання багатоетапного Dockerfile з Nginx для контейнеризації збірки.;
- очікувані результати - Готовий до продакшну, безпечний та високопродуктивний контейнеризований веб-застосунок..
