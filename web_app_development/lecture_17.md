# Лекція 17 (2 години). Безпека веб-додатків (XSS, CSRF, CSP) та оптимізація Core Web Vitals

## Тема лекції

Вразливості фронтенд-застосунків: атаки міжсайтового скриптингу (XSS), небезпека використання dangerouslySetInnerHTML, CSRF-захист. Безпечне збереження JWT-токенів автентифікації: чому LocalStorage вразливий та як використовувати HttpOnly Cookie. Метрики Core Web Vitals (LCP, INP, CLS), методи їх аудиту через Google Lighthouse та техніки прискорення завантаження сторінки.
