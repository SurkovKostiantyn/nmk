# Лабораторна робота №5 (2 години). Створення бібліотеки кастомних хуків для бізнес-логіки проєкту

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 9 та Лекція 10;
- мета роботи - Ізолювати бізнес-логіку та взаємодію з браузерними Web API у власні кастомні хуки.;
- практичні завдання - Розробка та підключення хуків useLocalStorage, useDebounce, useMediaQuery та useOnClickOutside; правильне оголошення масивів залежностей та реалізація функцій очищення (Cleanup).;
- очікувані результати - Модульний та чистий код компонентів, очищений від сайд-ефектів та низькорівневих викликів API..
