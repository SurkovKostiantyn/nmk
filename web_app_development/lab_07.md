# Лабораторна робота №7 (2 години). Маршрутизація React Router 7 та асинхронна інтеграція з API через TanStack Query

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 13 та Лекція 14;
- мета роботи - Реалізувати багатосторінкову SPA-навігацію та асинхронну взаємодію з REST API із серверним кешуванням.;
- практичні завдання - Налаштування маршрутів (Home, Catalog, Entity Details /items/:id, 404, Protected Route); інтеграція TanStack Query (useQuery, useMutation), обробка станів завантаження і помилок, інвалідація кешу та оптимістичний UI.;
- очікувані результати - Повноцінний багатосторінковий SPA-додаток, інтегрований із бекендом та автоматичним кешуванням даних..
