# Лекція 12 (2 години). Глобальне керування клієнтським станом: Context API проти Zustand

## Тема лекції

Межі можливостей Context API: проблема зайвих ререндерів усіх компонентів-споживачів при зміні окремих полів контексту. Сучасний підхід до Client State: чому індустрія відходить від важкого Redux на користь легковагого Zustand або Jotai. Створення сховища Zustand: селектори стану, екшени, іммутабельність та синхронізація з LocalStorage через мікро-мідлвари.
