# Лекція 15 (2 години). Автоматизоване тестування: Vitest, React Testing Library та Mock Service Worker

## Тема лекції

Піраміда тестування сучасного фронтенду. Філософія React Testing Library (RTL): тестування програми так, як нею користується реальна людина (без перевірки внутрішнього стану). Швидкий тест-раннер Vitest. Юніт-тестування кастомних хуків (renderHook). Мокінг мережевих API-запитів за допомогою MSW (Mock Service Worker). Огляд наскрізного тестування (E2E) з Playwright.
