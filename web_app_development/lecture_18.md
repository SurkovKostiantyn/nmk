# Лекція 18 (2 години). Виробнича збірка, оптимізація бандлу, CI/CD та хмарний деплоймент

## Тема лекції

Підготовка до релізу: аналіз розміру бандлу, Tree Shaking та динамічне завантаження коду (Code Splitting через React.lazy та Suspense). Налаштування автоматичного конвеєра CI/CD на GitHub Actions (лінтинг, типізація, тести, збірка). Контейнеризація за допомогою Docker (Multi-stage build з Nginx). Розгортання додатків на платформах Vercel, Cloudflare Pages та AWS. Підсумки дисципліни.
