# Лабораторна робота №6 (2 години). Впровадження глобального сховища Zustand із синхронізацією LocalStorage

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 11 та Лекція 12;
- мета роботи - Налаштувати централізоване глобальне сховище клієнтського стану на базі легковагої бібліотеки Zustand.;
- практичні завдання - Створення глобального стору для профілю користувача, налаштувань, кошика та черги сповіщень Toast; конфігурація атомарних селекторів стану для виключення зайвих ререндерів; підключення middleware persist.;
- очікувані результати - Масштабований глобальний стан проєкту зі збереженням між перезавантаженнями сторінки та високою продуктивністю..
