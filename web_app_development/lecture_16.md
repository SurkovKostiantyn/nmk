# Лекція 16 (2 години). Fullstack React та Server-Side Rendering: Server Components (RSC) та Next.js 15+

## Тема лекції

Стратегії рендерингу веб-сторінок: CSR, SSR, SSG та ISR. Революція React Server Components (RSC): виконання коду суто на сервері без додавання JS у клієнтський бандл. Директиви 'use client' та 'use server'. Екосистема Next.js 15+ з App Router: файлова маршрутизація, серверні дії (Server Actions) для мутації баз даних, оптимізація медіаконтенту.
