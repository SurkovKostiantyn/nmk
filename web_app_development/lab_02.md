# Лабораторна робота №2 (2 години). Побудова компонентної дизайн-системи застосунку на Tailwind CSS та Radix UI

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 3 та Лекція 4;
- мета роботи - Створити набір багаторазових презентаційних компонентів інтерфейсу за принципом Headless UI та утилітарної стилізації Tailwind CSS.;
- практичні завдання - Проєктування базових компонентів (Button, Input, Card, Badge, Modal) з типізованими пропсами, інтеграція бібліотеки class-variance-authority (cva) для керування розмірами та варіантами оформлення.;
- очікувані результати - Власна компонентна дизайн-система проєкту із підтримкою темної теми та адаптивної верстки..
