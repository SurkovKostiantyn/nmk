# Модуль 1. Основи декларативного програмування, архітектура та сучасний інструментарій

## Тиждень 1

## Лекція 1. Еволюція веб-технологій: від імперативного DOM до декларативного React ([Лекція 1. 2 години](lecture_01.md))
Еволюція веб-архітектури: перехід від багатосторінкових сайтів (MPA) до Single Page Application (SPA) та островної архітектури (Islands). Порівняння імперативного підходу (прямі маніпуляції з DOM API) із декларативним, що пропонує React. Архітектура Virtual DOM та механізм Reconciliation (алгоритм Diffing, волокна Fiber). Компонент як чиста функція від стану. Огляд сучасного стану екосистеми React 19.

## Лабораторна 1. Ініціалізація та побудова архітектури React-проєкту на Vite та TypeScript ([Лабораторна 1. 2 години](lab_01.md))
Створення базового каркаса семестрового курсового веб-додатка на стеку Vite + React 19 + TypeScript. Організація модульної файлової структури за принципами Feature-Sliced Design / модульного підходу (`src/components`, `src/features`, `src/types`), очищення шаблонного коду, налаштування аліасів імпорту (`@/*`) у `vite.config.ts` та `tsconfig.json`.

## Лекція 2. Сучасне середовище розробки: Vite, екосистема Node.js та стандарти якості ([Лекція 2. 2 години](lecture_02.md))
Чому Create React App (CRA) та Webpack поступилися місцем сучасним інструментам. Архітектура збирача Vite: використання Native ESM, esbuild та швидка гаряча заміна модулів (HMR). Організація структури монолітного та модульного фронтенд-проєкту. Конфігурація лінтерів та форматерів (ESLint, Prettier, Biome). Налаштування середовища розробки у VS Code.

## Практичне 1. Робота з Git, конфігурація лінтерів (ESLint, Prettier, Biome) та автоматизація перевірок ([Практичне 1. 2 години](practice_01.md))
Відпрацювання культури командної розробки: конфігурація та інтеграція ESLint (flat config) і Prettier; налаштування pre-commit хуків через Husky та lint-staged для автоматичного лінтингу й форматування коду; робота з системою контролю версій Git (Feature Branch Workflow, оформлення Pull Request, розв'язання конфліктів) за стандартами Conventional Commits.

## Лекція 3. Поглиблений синтаксис JSX, транспіляція та компонентно-орієнтований підхід ([Лекція 3. 2 години](lecture_03.md))
Природа JavaScript XML (JSX) як синтаксичного цукру: як транспілятори (SWC/Babel) перетворюють теги у виклики `jsx-runtime` (`_jsx`). Правила синтаксису, фрагменти (`<>`), вирази у фігурних дужках та обмеження JSX. Відмінності атрибутів HTML від пропсів JSX. Типізація функціональних компонентів за допомогою TypeScript. Побудова дерева компонентів.

## Лабораторна 2. Побудова компонентної дизайн-системи застосунку на Tailwind CSS та Radix UI ([Лабораторна 2. 2 години](lab_02.md))
Розробка атомарної бібліотеки повторно використовуваних UI-компонентів для навчального застосунку (Button, Input, Badge, Card, Modal/Dialog) з використанням Tailwind CSS та примітивів Radix UI (концепція Headless UI). Параметризація станів і розмірів за допомогою бібліотеки `class-variance-authority` (cva), реалізація адаптивності.

## Лекція 4. Стилізація сучасного React: Tailwind CSS, CSS Modules та дизайн-системи ([Лекція 4. 2 години](lecture_04.md))
Еволюція підходів до оформлення інтерфейсів: традиційний глобальний CSS, ізоляція через CSS Modules, парадигма CSS-in-JS та переваги Utility-First CSS (Tailwind CSS). Концепція Headless UI: розділення логіки та оформлення. Сучасні компонентні системи нового покоління (shadcn/ui, Radix UI). Організація дизайн-токенів, змінних CSS та реалізація темної теми (Dark Mode).

Односпрямований потік даних (One-Way Data Flow) та його вплив на передбачуваність системи. Незмінність пропсів (Read-Only). Робота зі спеціальним пропом `children`. ## Лабораторна 3. Інтерактивний інтерфейс каталогу та локальний стан на useState і useReducer ([Лабораторна 3. 2 години](lab_03.md))
Створення динамічного каталогу сутностей із панеллю фільтрації та локальним кошиком замовлень (або списком обраного). ## Тиждень 6

## Лекція 6. Локальний стан: хуки useState та useReducer, пакетне оновлення та іммутабельність ([Лекція 6. 2 години](lecture_06.md))
Природа стану в React: чому мутація локальних змінних не оновлює інтерфейс. Хук `useState`: синтаксис, відкладена ініціалізація та асинхронність. Механізм автоматичного пакетного оновлення (Automatic Batching). Робота зі складними станами (вкладені об'єкти, масиви) за принципом повної незмінності (Immutability). Хук `useReducer` для складної бізнес-логіки та кінцевих автоматів (FSM).

## Практичне 3. Алгоритми іммутабельної трансформації складних структур даних та бібліотека Immer ([Практичне 3. 2 години](practice_03.md))
Практикум з алгоритмів незмінної модифікації нормалізованих даних у JavaScript/TypeScript: оновлення вкладених об'єктів за допомогою spread-операторів, безпечна фільтрація, сортування та вставка елементів масивів. Розбір помилок мутації стану (anti-patterns). Спрощення редюсерів за допомогою бібліотеки Immer (`produce`).

## Тиждень 7

## Лекція 7. Рендеринг списків, алгоритм ключів (Keys) та патерни умовного відображення ([Лекція 7. 2 години](lecture_07.md))
Генерація динамічного інтерфейсу на основі масивів даних за допомогою методу `map()`. Критична роль пропу `key` для алгоритму Reconciliation: чому використання індексів масиву як ключів призводить до багів у стані та просідання швидкодії. Патерни умовного відображення: логічні оператори (`&&`), тернарні вирази, оператори нульового злиття (`??`) та патерн раннього повернення (Early Return).

## Лабораторна 4. Побудова динамічних списків та розробка форм із валідацією React Hook Form і Zod ([Лабораторна 4. 2 години](lab_04.md))
Відображення списків сутностей з коректними унікальними ключами, реалізація порожніх станів (Empty States) та скелетон-індикаторів завантаження (Skeleton UI). Створення форми додавання/редагування сутності на базі React Hook Form із декларативною валідацією через схеми Zod, динамічним виведенням помилок та підтримкою React 19 Form Actions (`useActionState`, `useFormStatus`).

## Тиждень 8

Система синтетичних подій (SyntheticEvent). Керовані (Controlled) та некеровані (Uncontrolled) компоненти. Використання хука `useRef` для прямого доступу до DOM-елементів. Архітектура валідації форм: декларативні схеми валідації Zod та бібліотека React Hook Form. Нові стандарти React 19: Form Actions, хуки `useActionState`, `useFormStatus` та `useOptimistic` для миттєвого відгуку UI.

## Практичне 4. Робота з подіями, некерованими компонентами через useRef та валідація схем у Zod ([Практичне 4. 2 години](practice_04.md))
Порівняльний практикум із Controlled та Uncontrolled полів введення. Застосування хука `useRef` для керування фокусом, програвання медіа та збереження змінних без виклику ререндерингу. # Модуль 3. Просунуті хуки, оптимізація та архітектура додатків

## Тиждень 9

## Лекція 9. Побічні ефекти, життєвий цикл та хук useEffect ([Лекція 9. 2 години](lecture_09.md))
Поняття Side Effects у функціональному UI. Життєвий цикл компонента: фаза рендеру (Render Phase) та фаза фіксації в DOM (Commit Phase). Хук `useEffect`: масив залежностей, проблема застарілих замикань (Stale Closures) та функція очищення (Cleanup Function) для запобігання витоку пам'яті. Подвійне виконання ефектів у StrictMode. Антипатерни: коли `useEffect` використовувати НЕ потрібно.

## Лабораторна 5. Створення бібліотеки кастомних хуків для бізнес-логіки проєкту ([Лабораторна 5. 2 години](lab_05.md))
Інкапсуляція повторюваної бізнес-логіки та інтеграції з Web API у типізовані кастомні хуки: `useLocalStorage` (для збереження налаштувань користувача), `useDebounce` (для оптимізації рядка швидкого пошуку), `useMediaQuery` (для адаптивних скриптів) та `useOnClickOutside` (для закриття модальних вікон і меню).

## Тиждень 10

## Лекція 10. Кастомні хуки (Custom Hooks): абстракція бізнес-логіки та Headless-патерни ([Лекція 10. 2 години](lecture_10.md))
Правила використання хуків (Rules of Hooks). Створення власних кастомних хуків для повторного використання поведінки (`useLocalStorage`, `useWindowSize`, `useDebounce`, `useMediaQuery`). Концепція Headless UI хуків: повна ізоляція логіки та стану від візуального представлення. Огляд бібліотек готових хуків (usehooks-ts).

## Практичне 5. Діагностика антипатернів useEffect, усунення Stale Closures та функція Cleanup ([Практичне 5. 2 години](practice_05.md))
Практичний розбір типових помилок життєвого циклу: усунення нескінченних повторних рендерингів (Infinite Loops), вирішення проблеми застарілих замикань (Stale Closures). Реалізація надійних функцій очищення (Cleanup): відписка від слухачів глобальних подій, очищення таймерів `setTimeout`/`setInterval` та скасування мережевих запитів через `AbortController`.

## Тиждень 11

## Лекція 11. Оптимізація продуктивності: useMemo, useCallback, React Compiler та Concurrent React ([Лекція 11. 2 години](lecture_11.md))
Механізм рендерингу та причини надлишкових обчислень. Класична мемоїзація: `React.memo`, `useMemo` та `useCallback` (виправдані сценарії та пастки передчасної оптимізації). Революція React 19 Compiler (React Forget): автоматична мемоїзація на рівні білда. Конкурентні можливості (Concurrent Features): пріоритезація UI через `useTransition` та `useDeferredValue`. Діагностика через React DevTools Profiler.

## Лабораторна 6. Впровадження глобального сховища Zustand із синхронізацією LocalStorage ([Лабораторна 6. 2 години](lab_06.md))
Переведення загальносистемного стану додатку (дані користувача, кошик товарів/список обраного, черга спливаючих сповіщень Toast) на стейт-менеджер Zustand. Мутації даних (useMutation), інвалідація кешу та оптимістичні оновлення (Optimistic UI) без очікування відповіді сервера.

## Лабораторна 7. Маршрутизація React Router 7 та асинхронна інтеграція з API через TanStack Query ([Лабораторна 7. 2 години](lab_07.md))

Інтеграція TanStack Query: виконання запитів через `useQuery`, оновлення сутностей через `useMutation`, інвалідація кешу та реалізація Optimistic UI для миттєвого відгуку кнопок лайків/видалення.

# Самостійна робота студентів (48 годин)

### Тема 1. Глибоке занурення в екосистему Next.js та Server Actions (10 годин)
Питання для опрацювання:
- архітектура App Router та маршрутизація через структуру папок;
- реалізація мутацій даних на сервері за допомогою Server Actions без створення окремих REST API ендпоінтів;
- стратегії кешування Next.js (Request Memoization, Data Cache, Full Route Cache);
- оптимізація статичних асетів (компоненти `next/image` та `next/font`).

### Тема 2. Просунуті інструменти тестування: MSW та E2E з Playwright (10 годин)
Питання для опрацювання:
- перехоплення мережевих запитів на рівні Service Worker за допомогою Mock Service Worker (MSW);
- написання надійних сценаріїв наскрізного тестування (End-to-End) у Playwright;
- тестування доступності інтерфейсу (Accessibility / a11y testing) за допомогою `axe-core`;
- автоматичний запуск тестів у headless-браузерах через CI/CD конвеєр.

### Тема 3. Стейт-менеджери: порівняння Zustand, Redux Toolkit та Jotai (10 годин)
Питання для опрацювання:
- архітектурний аналіз: підхід єдиного сховища (Zustand, Redux) проти атомарного стану (Jotai, Recoil);
- реалізація складного модуля (кошик інтернет-магазину зі знижками) з використанням Zustand;
- оптимізація ререндерів за допомогою кастомних селекторів та неглибокого порівняння (`useShallow`);
- міграція коду з Redux на сучасний Zustand: оцінка скорочення бойлерплейту.

### Тема 4. Створення власної бібліотеки кастомних хуків (8 годин)
Питання для опрацювання:
- розробка хука `useIntersectionObserver` для нескінченної прокрутки (Infinite Scroll);
- реалізація хука `useWebSocket` для обміну повідомленнями в реальному часі;
- розробка хука `useDebounce` та `useThrottle` для оптимізації частих подій вводу;
- публікація пакета власних хуків як npm-модуля.

### Тема 5. Підготовка, аудит та фінальний захист випускного проєкту (10 годин)
Питання для опрацювання:
- аудит швидкодії та доступності розробленого застосунку за допомогою Google Lighthouse;
- оформлення технічної документації в README (архітектура, інструкція запуску, змінні оточення);
- перевірка відповідності коду принципам чистого коду (Clean Code) та правилам SOLID;
- підготовка інтерактивної презентації та публічного деплою для захисту проєкту.
