# Практичне заняття №8 (2 години). Мокінг API через MSW, обробка помилок та розрахунок тестового покриття

## Методичні відомості

- відповідність лекціям - поглиблює та закріплює практичні навички Лекція 15 та Лекція 16;
- мета заняття - Закріпити навички створення надійних тестових сценаріїв для граничних та критичних ситуацій.;
- практичні завдання - Налаштування перехоплювачів Mock Service Worker для симуляції мережевих помилок (404, 500), затримок мережі та обривів з'єднання; перевірка коректності відображення блоків Error Boundary; налаштування звітів тестового покриття у Vitest.;
- очікувані результати - Стійкий до збоїв додаток із високим відсотком тестового покриття та гарантією коректної обробки помилок..
