# Лабораторна робота №4 (2 години). Побудова динамічних списків та розробка форм із валідацією React Hook Form і Zod

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 7 та Лекція 8;
- мета роботи - Реалізувати рендеринг колекцій даних та створити форму створення/редагування сутності з повноцінною валідацією схем.;
- практичні завдання - Генерація динамічних списків із використанням унікальних ідентифікаторів у пропі key; розробка складних форм на базі React Hook Form із декларативними схемами перевірки Zod; інтеграція React 19 Form Actions (useActionState, useFormStatus).;
- очікувані результати - Захищена форма з миттєвим виведенням інформативних помилок валідації та оптимістичним зворотним зв'язком..
