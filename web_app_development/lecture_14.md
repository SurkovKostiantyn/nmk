# Лекція 14 (2 години). Клієнтська маршрутизація у SPA: React Router 7 та TanStack Router

## Тема лекції

Принципи маршрутизації на стороні клієнта. Огляд React Router: декларативні маршрути, вкладені роути (Nested Routes) та компонент Outlet. Робота з параметрами URL (useParams, useSearchParams), програмна навігація (useNavigate). Захищені маршрути (Protected Routes) для авторизованих користувачів. Огляд типобезпечної маршрутизації (TanStack Router).
