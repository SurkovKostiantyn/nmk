# Практичне заняття №7 (2 години). Синхронізація фільтрів з адресою URL (useSearchParams) та інвалідація кешу

## Методичні відомості

- відповідність лекціям - поглиблює та закріплює практичні навички Лекція 13 та Лекція 14;
- мета заняття - Освоїти техніки синхронізації клієнтського стану з URL-адресою та тонке керування серверним кешем.;
- практичні завдання - Побудова механізму фільтрації, пошуку та пагінації, що зберігає свій стан у параметрах адресного рядка (useSearchParams); налаштування QueryClient: конфігурація staleTime, префетчинг даних (Prefetching) при наведенні миші та ручна інвалідація кешу.;
- очікувані результати - Створення зручного для користувача UI з можливістю ділитися посиланням на відфільтровані дані та миттєвим завантаженням..
