# Практичне заняття №6 (2 години). Профілювання рендерингу в React DevTools Profiler та застосування useTransition

## Методичні відомості

- відповідність лекціям - поглиблює та закріплює практичні навички Лекція 11 та Лекція 12;
- мета заняття - Опанувати інструментарій профілювання швидкодії React-інтерфейсів та механізми мемоїзації.;
- практичні завдання - Запис сесій та інтерпретація полум'яних графіків (Flamegraph) у React DevTools Profiler; виявлення непотрібних повторних рендерів; оптимізація через React.memo, useMemo та useCallback; застосування useTransition для збереження чуйності UI під час важких обчислень.;
- очікувані результати - Навички оптимізації швидкодії інтерфейсу та усунення "лагів" при активній взаємодії з користувачем..
