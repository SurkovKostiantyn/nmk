# Лабораторна робота №9 (2 години). Оптимізація бандлу, CI/CD на GitHub Actions та фінальний деплоймент додатку

## Методичні відомості

- відповідність лекціям - розробка базується на матеріалі Лекція 17 та Лекція 18;
- мета роботи - Оптимізувати додаток для релізу, налаштувати автоматизований пайплайн доставки та розгорнути його у хмарі.;
- практичні завдання - Оптимізація розміру бандлу за допомогою Code Splitting (React.lazy, Suspense); налаштування конвеєра CI/CD на GitHub Actions (перевірка типів, запуск тестів, збірка); публічний деплой на Vercel або Cloudflare Pages.;
- очікувані результати - Опублікований робочий проєкт у портфоліо студента з налаштованим процесом неперервної інтеграції..
