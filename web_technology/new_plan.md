Нові теми (14 - 24): 

### Змістовний модуль 4. Архітектура веб-додатків та екосистема JavaScript (без фреймворків)

### 14 Просунута робота з DOM та подіями - делегування подій (Event Delegation), Drag-and-Drop, MutationObserver.

### 15 Клієнтська валідація та робота з формами - обробка об'єкта FormData, регулярні вирази, кастомні повідомлення про помилки.

### 16 Збереження стану на клієнті - Web Storage API (localStorage, sessionStorage) та основи роботи з IndexedDB.

### 17 Модульна архітектура додатків - використання ES Modules, налаштування та використання сучасного збирача проєктів (Vite).

### 18 Об'єктно-орієнтований підхід в розробці UI - створення незалежних UI-віджетів через класи, основи Web Components (Custom Elements).

### 19 Архітектурні патерни на клієнті - патерн MVC (Model-View-Controller) на чистому JS, ізоляція бізнес-логіки від відображення.

### 20 Екосистема та управління залежностями - робота з менеджером пакетів (NPM), інтеграція сторонніх UI-бібліотек (наприклад, графіків або слайдерів).

### 21 Взаємодія з сучасними Web API - Intersection Observer (для лінивого завантаження), Geolocation, Web Notifications API.

### 22 Основи тестування JavaScript-коду - модульне тестування бізнес-логіки за допомогою сучасних інструментів (Vitest або Jest).

### 23 Автоматизація та розгортання додатків - підключення CI/CD, автоматичний деплой проєктів на платформи Vercel або Netlify.

### 24 Оптимізація та захист проєкту - базовий аудит продуктивності (Lighthouse), підготовка до презентації фінального додатка.
