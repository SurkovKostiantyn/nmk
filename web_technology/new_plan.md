Нові теми (14 - 24): 

### Змістовний модуль 4. Архітектура веб-додатків та екосистема JavaScript (без фреймворків)

### 14 Просунута робота з DOM та подіями - делегування подій (Event Delegation), Drag-and-Drop, MutationObserver.

### 15 Обробка даних на клієнті та робота з формами - функції для роботи з рядками, методи-ітератори масивів (map, filter, reduce), базова валідація даних форми.

### 16 Збереження даних користувача - використання Web Storage API (localStorage, sessionStorage) для створення "пам'яті" сторінки (наприклад, збереження теми або списку задач).

### 17 Таймери та прості ефекти - використання setTimeout та setInterval, створення простих елементів (наприклад, слайдер, таймер зворотного відліку) на чистому JS.

### 18 Поглиблена робота з об'єктами - деструктуризація, поверхневе та глибоке копіювання, організація та форматування даних для підготовки до роботи з бекендом.

### 19 Використання готових рішень - підключення сторонніх UI-бібліотек та плагінів через CDN (наприклад, готові слайдери, іконки, прості анімації без складної збірки).

### 20 Структурування коду - базове розуміння ES Modules (import та export), щоб розбити код на логічні частини замість одного великого файлу.

### 21 Робота з медіа на веб-сторінках - керування відтворенням звуку та відео через JavaScript, створення простого кастомного плеєра.

### 22 Розгортання (деплой) веб-додатків - огляд сучасних платформ для безкоштовного хостингу (Vercel, Netlify, Firebase Hosting) та процес публікації готового проєкту.

### 23 Основи взаємодії з бекендом та бази REST API - розуміння архітектури клієнт-сервер, концепція CRUD (створення, читання, оновлення, видалення) та тестування запитів.

### 24 Поєднання фронтенду з PHP-бекендом - відправка даних з клієнтських форм на сервер, обробка відповідей та динамічне відображення даних з бази на веб-сторінці.
