# Лабораторна робота 14: Реалізація Drag and Drop в інтерфейсі вебмагазину

## Опис роботи
У цій лабораторній роботі реалізовано взаємодію з товарами шляхом перетягування (Drag and Drop) за допомогою нативного HTML5 Drag and Drop API. Користувач може перетягувати картки товарів у спеціально виділену інтерактивну зону скидання (Drop Zone).

---

## Що було зроблено:
- підготовка карток до перетягування - додано атрибут `draggable="true"` до елементів `.product-card` та вимкнено стандартне перетягування зображень через `draggable="false"`;
- передача даних через DataTransfer - у події `dragstart` зберігається ID товару за допомогою `event.dataTransfer.setData('text/plain', ...)` та призначається стиль `.dragging`;
- завершення стану перетягування - у події `dragend` клас `.dragging` видаляється для відновлення звичайного вигляду картки;
- створення зони скидання (Drop Zone) - додано блок `#dragAndDropZone` з `position: sticky`, пунктирною рамкою та підсвічуванням `.drag-over`;
- обробка наведення на зону скидання - у подіях `dragover` та `drop` скасовано стандартну поведінку браузера через `event.preventDefault()`, що уможливлює подію скидання;
- отримання даних і додавання товару - у події `drop` зчитується збережений ID через `event.dataTransfer.getData()`, товар знаходиться в `globalStoreProducts` та його назва виводиться всередині зони скидання;
- адаптивне налаштування сітки - використано CSS Grid із `repeat(auto-fit, minmax(280px, 1fr))` та властивість `object-fit: contain` для коректного масштабування фотографій товарів.

## Підсумок
Робота закріпила практичні навички роботи з HTML5 Drag and Drop API: використання об'єкта DataTransfer, обробку подій `dragstart`, `dragend`, `dragover`, `dragleave`, `drop` та інтерактивну візуалізацію станів елементів у процесі перетягування.
